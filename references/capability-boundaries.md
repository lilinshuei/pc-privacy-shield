# 能力边界与威胁模型

> 本文件是 `SKILL.md` 第 5 节的展开。**向用户交付时必须复述边界，不得宣称「装了就防远控 / 防一切截屏」。**

## 一、三类威胁，天花板完全不同

| 威胁 | 能不能防 | 靠什么 | 说人话 |
|---|---|---|---|
| 截屏 / 录屏 / 远控 / 屏幕共享 | **能防一大半，且无感** | 主线 A · WDA | 给窗户装单向玻璃：你这边看得见，拍出来的画面里是黑的 |
| 注入式截屏 / 驱动级捕获 | **WDA 挡不住** | 托盘「强制遮蔽」兜底 | 拿块黑板只盖住这个窗口；屏幕上看得见，但任何截屏手段都拍不到内容 |
| 文件被拷走 / 云同步 / 电脑被翻 | **主线 A 完全不管** | 主线 B · 加密 | 磁盘上只剩解不开的乱码；没口令读不出来 |
| 键盘记录 / 身后的人 / 已入侵本机 | **都防不住** | — | 数据到了别人手里或别人站在背后，前端无解 |

## 二、和常见做法的区别

| 做法 | 每次看的成本 | 屏幕上有无遮挡 | 防截屏 / 远控 | 防文件被拷走 |
|---|---|---|---|---|
| 加密文件 / 加密压缩包 | 输口令、解压 | 无 | 解锁后不防 | **防** |
| 防窥贴膜 | 无 | 物理变暗 | 只防斜视 | 不防 |
| 一键黑幕开关 | 记得开、记得关 | **有，且常是全屏** | 开着的那一刻防 | 不防 |
| **本 Skill · A 线** | **零操作** | **零遮挡** | **持续防**（有边界） | 不防 |
| 本 Skill · B 线 | 输口令 | 无 | 解锁后不防 | **防** |

一句话：**A 管「别人看到」，B 管「别人拿走」，两者不能互相替代。** 只想要前者就别被塞一个口令；真怕文件被拷走就必须接受口令。

## 三、逐条边界（对应 SKILL.md 第 5 节 1–12 条）

1. **WDA 不是加密**：原文件仍是明文，不防文件被复制、被云同步、被已入侵本机的程序读取。
2. **WDA 挡不住**注入式截屏（进程内 hook DWM）、驱动级捕获；已建立的远控会话常需重建窗口才生效。此时用托盘「强制遮蔽」。
3. **按 MSDN，`WDA_EXCLUDEFROMCAPTURE` 只作用于属于当前进程的窗口**；对记事本这类第三方窗口能否设置由脚本启动时实测，不预先断言，失败即降级为自建查看器。
4. 不防键盘记录、麦克风/摄像头、站在身后的人。
5. 强制遮蔽的黑板在你自己屏幕上**看得见**；它只盖目标窗口、鼠标穿透，但不是视觉无感。
6. 加密方案的口令丢失 = 数据不可恢复，无后门。
7. 所有检测均为只读提示，不结束进程、不改注册表、不改文件关联、不改系统设置、不装驱动、不写开机自启。
8. 全程离线、零依赖：不引 CDN、不引 npm 包，主路径不需要 Python / Node 运行时。
9. **不删除任何文件**。保存只做「写回原文件 + 新增一份备份」，不删除/不移动/不重命名任何现有文件。
10. **编辑只发生在防护查看器（模式 B）**；模式 A 请直接在记事本里编辑与保存。
11. **保存是有代价的写操作**：会更新原文件内容与修改时间（格式不变）；备份文件是**明文副本**，位于 `%APPDATA%\PCPrivacyShield\backups\`，与原件同等敏感。自动备份只增不删，长期累积会占用少量空间。
12. **格式保真的边界**：编码与换行按「探测到的主风格」还原；若原文件混用多种换行，保存后会统一为主风格（CRLF / LF / CR 之一）。

## 四、谁适合用 / 谁不适合

**适合**：本机长期放敏感文本、经常远程协助或共享屏幕、不想每次输密码、也不想被「开一下关一下」打断的人；以及想给内部网页工具加防窥开关的开发者。

**不适合**：需要对抗注入式 / 驱动级截屏、需要合规级审计或防内鬼、文件频繁外发且不能接受口令、或者期待「装了就绝对安全」的场景。这些请走加密 + 权限管控 + 终端安全方案，本 Skill 不替代它们。

## 五、WDA 能防与不能防的具体对象

**能防**：DXGI 桌面复制、系统截屏（PrintScreen / 截图工具）、向日葵 / ToDesk / TeamViewer 等远控画面、Teams / Zoom 等屏幕共享。

**不能保证**：注入式截屏（进程内 hook DWM）、驱动级捕获、已建立的远控会话（通常要重建窗口才生效）、键盘记录、麦克风 / 摄像头、身后的人。
